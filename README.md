# 📚 Aula de JavaScript - Conversão de Moedas

Atividade prática para desenvolver lógica de programação utilizando JavaScript.

## 🎯 Objetivo

Criar um programa que:

- Receba a cotação do dólar;
- Receba um valor em dólares;
- Converta o valor para reais;
- Exiba o resultado ao usuário.

## 🧩 Conceitos Trabalhados

- Variáveis (`let`)
- Entrada de dados (`prompt()`)
- Conversão de tipos (`Number()`)
- Operações matemáticas
- Algoritmos
- Entrada, processamento e saída de dados

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
