03 — Variáveis

Guardando os valores

O programa precisa guardar as informações recebidas para poder utilizá-las posteriormente.

Em JavaScript utilizamos let para criar variáveis. 

let cotacao = 5;

Podemos também guardar o valor em dólares. 

let dolares = 100;
💡 Os nomes das variáveis devem ajudar a entender o que está sendo armazenado.

Prefira nomes como cotacao e dolares em vez de nomes genéricos como x e y.
04 — Entrada de dados

Recebendo informações

Podemos utilizar o prompt() para solicitar informações ao usuário. 

let valor =

Como o programa realizará cálculos, precisamos trabalhar com números.

Para converter o texto recebido em número, utilizamos Number(). 

let valor =

06 — Conceito

O que é cotação?

A cotação indica quanto uma unidade de uma moeda vale em relação a outra moeda.

Imagine, apenas como exemplo didático, que a cotação seja:

R$ 5,00

para cada US$ 1,00

Isso significa que um dólar está sendo considerado, neste exemplo, como equivalente a cinco reais.

⚠️ Este valor é apenas um exemplo didático. A atividade pedirá que o usuário informe a cotação do dia.

Por que a cotação é necessária?

Porque o valor informado em dólares não está originalmente expresso em reais.

Precisamos utilizar a cotação para estabelecer a relação entre as duas moedas.

✔️ O objetivo do programa não é simplesmente mostrar o valor informado pelo usuário.

É necessário realizar uma operação para transformar o valor de uma moeda em outra.
08 — Matemática

A multiplicação em JavaScript

Para multiplicar dois valores em JavaScript, utilizamos o operador: 

*

Por exemplo: 

let resultado = 10 * 5;

Nesse caso, dois valores estão sendo multiplicados.

💡 Na matemática usamos o símbolo ×.

Em JavaScript usamos *.

Pense no problema

Se você conhece:

  • o valor em dólares;
  • a cotação;

qual operação pode relacionar essas duas informações para obter o valor em reais?

🧠 Não copie uma fórmula. Entenda o que a cotação representa e descubra a operação necessária.
09 — Exemplo conceitual

Pense como um comprador

Imagine que uma pessoa queira comprar uma determinada quantidade de dólares.

Para descobrir quanto ela precisará pagar em reais, temos:

Informação A

Quantidade de dólares desejada.

Exemplo: US$ 100

Informação B

Cotação utilizada.

Exemplo: R$ 5,00

A pergunta que devemos fazer é:

"Se eu sei quanto vale 1 dólar, quanto preciso pagar para comprar vários dólares?"

Essa pergunta deve levar você a descobrir a operação matemática necessária.

⚠️ O objetivo deste exemplo é desenvolver o raciocínio. Não utilize os valores acima como resposta da atividade.
